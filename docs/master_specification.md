# Rashizun IDE: Master Specification (v1.0.0)

## 🌌 Vision
Rashizun is an AI-Native, web-first IDE designed for the **Omni-Execution Protocol 2026**. It transforms the coding experience from a passive editor into an active **Architectural Orchestrator**.

## 🏗️ Core Architecture
The IDE is built on a distributed microservice stack:
*   **IDE Core**: Browser-native VSCodium with the `rashizun-core` extension.
*   **MCP Core**: The bridge between UI actions and backend specialist tools.
*   **RAG Engine**: Vector-memory for architectural provenance using LanceDB.
*   **Skill Registry**: A dynamic repository of automation skills (Deployment, Audit, Cost Analysis).

## 🧭 The 7-Stage Lifecycle
1.  **Discovery**: Identifying MVP and strategic alignment.
2.  **Architecture**: Mapping microservices and AI-first design.
3.  **Sprint Planning**: Iterative roadmaps and workload estimation.
4.  **Development**: AI-assisted implementation (Ghost Text).
5.  **Testing**: Automated SAST/DAST and compliance.
6.  **Deployment**: Cloud-agnostic deployment via MCP skills.
7.  **Maintenance**: Observability and automated retraining.

## 📜 Project Ledger
Every architectural decision is tracked in the **Project Ledger** (`.rashizun/ledger.json`). This ensures that the AI assistant always understands the *why* behind the code, not just the *what*.
